Quick start

Get the bodycam running

Two resources, one config file. If you want the full tour instead - architecture, every page, self-hosting - see the full guide.

1. Grab the resources

The bodycam

Records the officer's view, uploads it here. Start with this one.

opslabs-bodycam
License client

Required alongside it - activates your license key.

opslabs-license

The in-hand tablet, LB Phone app and live-roster sync are optional modules built into opslabs-bodycam itself (config_server.lua → ServerConfig.Modules) - nothing extra to install, turn any of them off there if you don't want them.

2. Install it

1
Download & drop it in

Get it from your license portal, unzip opslabs-bodycam and opslabs-license into your FiveM server's resources/ folder.

2
Paste your setup block into opslabs-bodycam/config_server.lua

Copy it from your integration page into its ServerConfig.XonSight block, replacing the two example lines. That's the whole connection - URL and token, done.

3
Set up the license

In opslabs-license/config.lua, set your license key (or enter it once on the OPS Phone's license screen in-game).

4
Add it to server.cfg

ensure opslabs-license then ensure opslabs-bodycam, then restart the resource.

That's it

Your first recording should show up on the Dashboard within a few seconds.
