{{ icon("evidence", "h-4 w-4 text-accent2") }} Footage hosting

Newer opslabs-bodycam builds upload recordings to this portal automatically - nothing to do here, just leave Storage.PublicUrl blank in config_server.lua. The companion script below is only for a less common setup: hosting the files yourself, pushed from a different machine than the one running your FXServer (e.g. a separate storage box) - run it there, pointed at wherever the resource's media/ folder actually lives.

{{ icon("external-link", "h-3.5 w-3.5") }} Download upload-companion.py
Run it like this (already filled in for {{ community.name if community else "this server" }}):
pip3 install requests
python3 upload-companion.py --media-dir /path/to/opslabs-bodycam/media \
  --portal-url {{ request.url_root.rstrip("/") }} \
{% if community %}  --token {{ community.api_token }}{% else %}  --key YOUR-XONSIGHT-WEBHOOK-KEY{% endif %}

Then in config_server.lua, set:

PublicUrl = '{{ request.url_root.rstrip("/") }}/media',

Newer and less battle-tested than self-hosting the folder with your own nginx (README.md, Install step 3) - if in doubt, self-host instead.
