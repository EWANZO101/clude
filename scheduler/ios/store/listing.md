## App Privacy ("nutrition label")

Tracking: **No** (the app doesn't track users or share data with data brokers or advertisers).

Data collected, all **linked to the user**, all used for **App Functionality** only:
- **Contact Info → Email Address** (sign-in)
- **Contact Info → Name, Email Address, Phone Number** (customers' booking details shown in the app)
- **User Content → Other User Content** (booking notes)
- **Identifiers → Device ID** — answer this only if asked about push tokens; many developers leave push tokens out, but declaring it is the safe choice.

> Scheduler is a companion app for owners of a Scheduler booking website (scheduler.opslabsystems.cloud). Accounts are created on the website by the site owner; there is no sign-up in the app, so there is no account deletion flow.
>
> The demo account above contains sample bookings so every screen can be reviewed.
