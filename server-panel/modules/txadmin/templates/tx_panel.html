Good to know

      

        
Where do I find my session?
On claude.ai/code (or the Code tab in the Claude app), look in the session list for the name shown under Linked folders, like {{ inst.name }} · resources. Click it and start typing.

        
When do my changes show up in game?
Files change on the server as soon as Claude saves them. FiveM only loads them when the resource restarts, so open the Resources tab and press Restart on it. For big changes, use Restart at the top of the page.

        
Why does Claude ask before it does things?
With “Ask me first”, Claude shows you each file edit or command in claude.ai and waits for you to approve it. That's the safest setting for a live server. You can relink with “Edit files without asking” if you trust it to just get on with it.

        
Does it stop when I close the browser?
No. The link keeps running on the server, even after panel restarts and reboots. Use Stop or Unlink on this page to turn it off.

        
Is it safe?
Only full admins of this panel can set it up, and it uses the Claude account shown at the top of this page. Claude runs on the server itself, so treat access to that Claude account like the server's admin password.

        
Something's wrong?
Press Session on a linked folder to see Claude Code's screen on the server. If a link says Stopped with an error, press Start again. If it keeps happening, Unlink it and link it again.
