Quick guide

Shortcuts and tips for working in the .env editor.

Keyboard shortcuts

  • Ctrl + SSave the open file
  • Ctrl + ScrollZoom the editor text in or out
  • Ctrl + + / −Zoom in / zoom out
  • Ctrl + 0Reset zoom to 100%

Finding & opening files

  • Click any file in the left-hand list to open it.
  • Use the filter box to search by path or service name.
  • Browse files lets you pick any file on the server, including hidden ones the scanner missed.
  • New .env file creates an empty file at a path you type in.

Editing

  • Code mode is the raw file, exactly as it will be written.
  • Placeholders mode shows each KEY=VALUE pair as its own row — easier to scan and edit without touching syntax.
  • Fullscreen editor expands just the editor pane; the file list and main sidebar stay put.

Before you save

  • Saving writes straight to disk on the server — there's no draft or undo history once saved.
  • Use Backup copy to snapshot a file before a risky edit.
  • Download or Copy all if you want a local copy before you change anything.
