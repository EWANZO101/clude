Leaving the start command blank stops the kiosk process and clears supervision entirely — saving with it blank now requires ticking the confirmation checkbox above, so this can't happen by accident. Every save of this form resets all fields above to what's submitted this time (pre-filled with what the Admin Panel last sent, above) — re-enter anything you want to keep that isn't already filled in.

Advanced: run a command on this kiosk {{ icons.icon('chevron', 14) }}

Runs on the kiosk exactly as typed (its own shell — cmd.exe on Windows, sh on Linux), with no restrictions and no sandbox. Output (or the exit code) shows up below in Recent commands once the Agent picks it up. There's no live remote-desktop session yet — this is one-shot execution, not an interactive shell. Avoid anything that stops or restarts the Agent's own service from within this command — it can't finish stopping itself while still running it.

Danger zone: reset kiosk database {{ icons.icon('chevron', 14) }}

Wipes every item, tool, local user, project, wire spool, and audit out of this kiosk's local database — everything, not just inventory. The Agent takes a full backup and uploads it here (source "pre_reset", visible in this instance's backup history) before wiping anything, so it's recoverable via restore, but the reset itself cannot be undone once the Agent has run it.

Danger zone: update Agent (agent_version {{ instance.agent_version or '?' }}) {{ icons.icon('chevron', 14) }}

Pushes the Agent code currently on this server (agent/, rebuilt fresh from disk first) onto this one instance's live Agent service. A detached helper process on the machine stops the service, swaps just the agent/ folder, and restarts it — the service is briefly unreachable during that restart, and this Agent has no auto-update or automatic rollback, so a failed swap needs manual fixing on the machine (see downloads/agent_update_log.txt in its install folder).
