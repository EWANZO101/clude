Privacy & Data Retention

POPIA-relevant controls for the personal information this kiosk stores (local user accounts, login/checkout/issuance history, admin audit log). See also the public privacy notice shown to staff.

Retention

{% if configured_retention_days %} Records are auto-purged once they're older than {{ configured_retention_days }} days (set via the Client Portal / Instance Agent config). {% else %} No automatic retention window is configured — history accumulates indefinitely until purged manually below or a retention period is set via the Client Portal. {% endif %}

Only closed/historical rows are ever eligible: an in-progress tool checkout or open wire issuance is never purged regardless of age. Manual purges are logged to the audit log below.

Data subject requests

To erase a former staff member's personal data (username/badge/password), deactivate their account, then use Erase personal data on the Users page. Historical custody/safety records (who had which tool/PPE/wire and when) are kept as a separate business record and aren't affected — see the note on that action.
