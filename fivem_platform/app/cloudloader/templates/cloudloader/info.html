Install CloudLoader

One resource, one line in server.cfg, covers every {{ config.SITE_NAME }} script you own. No editing config files per product — attach purchases to your server from the portal instead.

Download CloudLoader.zip
Building something custom? See the API reference →
  1. 1. Extract the zip into your server's resources/ folder.
  2. 2. Register a server in {% if current_user.is_authenticated %} your portal — {% else %} your portal (log in or sign up first) — {% endif %} you'll get a one-line token to add to server.cfg: 
    ensure cloudloader
setr cloudloader_server_token "srv_..."
  3. 3. Attach your purchases to that server from the same portal page — anything bought with your account email shows up there automatically, no license keys to copy by hand.
  4. 4. Restart your server. CloudLoader fetches everything attached to that token automatically. Attach a new purchase later and it picks it up on the next re-check — no restart even required.
