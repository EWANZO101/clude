❓ HOW GIVEAWAYS WORK
🎁 Prize types
🏷 Discount Code — each winner gets their own single-use code (e.g. 20% or $10 off) DM'd to them.
🎨 Free Art Piece — each winner gets a single-use 100%-off code for the commission type you pick.
✨ Something Else — anything you like; you sort out delivery with the winner yourself.
🏆 Win modes
🎲 Random draw — entries stay open until the timer ends, then winners are picked at random.
⚡ First come, first served — the first N people to enter win instantly; it ends as soon as all prizes are claimed (or when time runs out).
📦 Delivery & rerolls
Winners are pinged in #giveaways and DM'd (with their code, if the prize has one). Codes show up under Discount Codes. Rerolling a winner switches off their code if it hasn't been used and picks someone new.
